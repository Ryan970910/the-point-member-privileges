# The Point 普通會員禮遇整理（非 The Point Gold）

本 repo 整理香港新鴻基地產旗下購物消閒會員獎勵計劃 **The Point**（[www.thepoint.com.hk](https://www.thepoint.com.hk)）之**普通會員（非 The Point Gold）禮遇**，以 Excel 檔案呈現。

## 檔案

- [`The_Point_Member_Privileges.xlsx`](./The_Point_Member_Privileges.xlsx)

### 工作表內容

| 工作表 | 內容 |
|--------|------|
| 普通會員禮遇總覽 | 會籍基本、賺分、積分兌換、商戶優惠、泊車、服務及夥伴禮遇一覽 |
| 會員vs Gold對照 | 普通會員與 The Point Gold 會員的禮遇對照表 |
| 賺分途徑 | 商場消費、生日積分、SmarTone、Go Royal、YATA、club1933、HSBC 等賺分詳情 |
| 兌換及泊車禮遇 | Point Dollar、免費泊車、電動車充電、精選禮品等兌換詳情 |
| 資料來源 | 各官方頁面連結及擷取日期 |
